# ADR-0011 — Cross-brand Supplier Directory

- Status: `Proposed`
- Owner: Procurement Product Owner
- Affected modules: Procurement, Inventory, BOP Directory
- Source: Canonical Handoff Section 80.7, version `0.5.3`

## Context

Supplier ownership remains tenant-scoped in the current baseline.

## Decision

Do not introduce a cross-brand Supplier Directory now.

## Consequences

Tenant consent and ownership are not weakened by premature shared identity.

## Revisit trigger

A marketplace/shared supplier identity and consent model is committed, before cross-brand procurement.
