# ADR-0003 — Generic Workforce / Scheduling Domain

- Status: `Proposed`
- Owner: Product + Architecture Owner
- Affected modules: Delivery, Store Ops, Kitchen, Identity
- Source: Canonical Handoff Section 80.7, version `0.5.3`

## Context

Delivery worker availability is sufficient for the current v0.1 scope.

## Decision

Do not add a generic Workforce or Scheduling Domain now.

## Consequences

No shift planning, labor-compliance, time-clock, or multi-domain staffing platform is implied by current delivery availability.

## Revisit trigger

Shift planning, labor compliance, time clock, or multi-domain staffing enters committed scope, before the workforce Phase.
