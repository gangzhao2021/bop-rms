# ADR-0027 — Pilot Corporate Formation Planning Profile

- Status: `Accepted`
- Owner: Product Owner + Legal / Finance Owners
- Affected modules: Operating Entity, Tax, Payment, Compliance
- Source: Canonical Handoff Sections 80.7 and 86, version `0.5.3`

## Context

A bounded formation-planning profile is needed without treating personal, legal, or tax facts as known.

## Decision

Plan for simple single-founder control, one voting common share class, one director/officer profile, an Ontario professional registered office, and a December 31 fiscal year. Real personal and filing data require lawyer/accountant evidence.

## Consequences

This ADR does not identify a person, create ownership, provide professional advice, file documents, or create external accounts.

## Revisit trigger

Before filing, real ownership, tax, investment, immigration, estate, or professional evidence requires another structure.
