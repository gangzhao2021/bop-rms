# ADR-0026 — Pilot Corporate Name Mode

- Status: `Accepted`
- Owner: Product Owner + Legal / Compliance Owner
- Affected modules: Operating Entity, Brand, Compliance
- Source: Canonical Handoff Sections 80.7 and 85, version `0.5.3`

## Context

The pilot needs a legal-name planning mode distinct from Brand and operating names.

## Decision

Use a numbered Ontario corporation as the planned legal name. Brand and operating name remain separate.

## Consequences

No specific corporation number, legal name, registration, or filing is invented by this ADR.

## Revisit trigger

Before filing, professional review requires a change, or a later approved legal-name amendment is pursued.
