# ADR-0023 — Ontario Pilot Jurisdiction

- Status: `Accepted`
- Owner: Product Owner + Compliance Owner
- Affected modules: Tax, Payment, Compliance, Localization
- Decision date: 2026-07-15
- Source: Canonical Handoff Sections 80.7 and 82, version `0.5.3`

## Context

The Canada-first pilot required one Province planning baseline.

## Decision

Use Ontario as the first Canada production-pilot jurisdiction profile. Currency remains CAD.

## Consequences

Ontario-specific planning is allowed, but no registration, professional advice, Provider account, or live tax result is claimed.

## Revisit trigger

The first Pilot Province changes before irreversible registration or Provider commitment.
