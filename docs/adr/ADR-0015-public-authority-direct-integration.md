# ADR-0015 — Public Authority Direct Integration

- Status: `Proposed`
- Owner: Compliance Owner
- Affected modules: Compliance, Tax, Operating Entity
- Source: Canonical Handoff Section 80.7, version `0.5.3`

## Context

Export and evidence workflows are preferred before direct regulator integration.

## Decision

Do not add a public-authority API integration in the current baseline.

## Consequences

No regulatory endpoint, credential, submission result, or legal compliance claim is invented.

## Revisit trigger

A jurisdiction mandates direct API submission, before the jurisdiction-specific milestone.
