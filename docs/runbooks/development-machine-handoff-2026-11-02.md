## 一键换到新 Mac

交接包不在仓库里，因为它含密钥和测试凭据。

1. 旧电脑：双击桌面的“在旧电脑双击打包”，设一个密码，桌面会生成 `bop-rms-交接包.dmg`（约 540MB，AES-256 加密）。
2. 用隔空投送或硬盘传到新电脑的“下载”文件夹。
3. 新电脑：打开“终端”，粘贴这一行，按回车，按提示输入打包密码。

   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/gangzhao2021/bop-rms/codex/wp-2402-pilot-submission/tooling/environment/setup-mac.sh)"
   ```

只想要代码和开发工具时，第 3 步不需要交接包；之后把交接包放进“下载”再运行一次，就会补上测试环境。

安装脚本会等你装好 Xcode 命令行工具和 Docker Desktop（需要你点确认），然后自动取出代码和资料、恢复数据库、构建并启动 v15、放好记忆和脚本、安装开发依赖。中途失败时解决问题后再运行一次，已完成的步骤会跳过。恢复前会按备份清单核对每张表的行数，对不上就停下。

2026-11-02 在旧 Mac 上用临时目录、临时数据卷和临时 Compose 项目完整演练过：643 张表 1,608,141 行全部相符，12 张照片恢复，四个入口 200，31 项服务 running，无 level 50/60；店员登录、积分页、Store 2 入口、一张 TEST 自取单模拟付款正常。演练后已删除临时内容，并恢复原 v15。
