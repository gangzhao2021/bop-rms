# Ordinary Product publication requests

WP-2421 milestone95 integrates the publication request panel into the existing
CAT-PRODUCT-EDIT route and Merchant components. Section88 supplies roles,
permissions, context, states, reflow, keyboard and privacy rules; this repository
software design uses existing Merchant layout without inventing a Figma authority.

Open/refresh reads current management through94 and93. Tenant comes from the
verified owning editor read; Brand comes from the current Store capability, then
both bind the management source. Product/Store/CSRF replacement unmounts and aborts
old work. Recorded version selection displays labels/state/revision, never raw
identities, hashes, validation evidence or Actor data. Current validation remains
incomplete and server permission/approval/topology/policy admit every request.

An explicit initial Draft proposes only the selected Store and requires user
IANA zone/local time/UTC offset. Existing records initialize their exact period
and scope; schedule reschedule/cancel keeps original schedule identity. All eight
User intents are supported where their recorded lifecycle applies. Independent
approval uses current authenticated backend Actor and policy, without an Actor
picker. System activation stays outside the browser. Current sale eligibility is
never inferred from Approved, Scheduled or Published history.

Unknown outcomes retain the94 original request and hide new controls, lock
refresh and expose explicit retry after access restoration. Offline, background,
exclusive expiry or denial hides sources and editable fields. Receipt advances
only an expected revision; actual refresh is required to read recorded results.
Unsaved period intent persists across short observation expiry. BeforeUnload
warns for edited/executing/unconfirmed intent; durable internal navigation and
restart recovery remain open. This panel does not supply current source gaps.

Browser verification uses real local Chromium/HTTP and explicitly synthetic
owning projection/native-shaped receipt conditions. Native SQL and encrypted
session source/replay evidence remain92/91, distinct from these UI scenarios.
