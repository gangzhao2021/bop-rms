# DEC-ALLERGEN-DECLARATIONS — 品牌过敏原名册与配料声明

状态：**Accepted（实现决定）**。2026-10-08，在 Owner 的商用原则与技术选择授权下作出。
执行工作包：[WP-2423](../work-packages/WP-2423.md)（顺序第 8 步，切片 8.4）。

## 背景

菜单提交审核要求每个上架规格有完整的过敏原来源（名册版本、配方经配料推导的证据）。原模型只能记录“含有/可能交叉接触/未核实”，
无法表达“经核实不含任何优先过敏原”，配方也从不携带配料声明，因此任何菜单都无法通过真实审核。

## 决定

1. **品牌过敏原名册**：一个名册版本列出品牌要披露的过敏原（最新的已批准版本为当前名册），批准需 `catalog.allergen_registry.manage`。
   试点名册为 **TEST-ONLY**：Health Canada 优先食物过敏原与麸质来源（花生、坚果、芝麻、牛奶、蛋、鱼、甲壳类与软体动物、大豆、
   小麦与黑小麦、麸质来源、芥末、亚硫酸盐），页面与记录注明“商用前须按 Health Canada 现行指引核对”。同一过敏原跨名册版本保持同一标识。
2. **配料声明**：对配料的**当前版本**、按**当前名册**逐项决定：不含 / 含有 / 可能含有（交叉接触），并记录依据（供应商规格书、
   产品标签、生产商声明）、文件说明、备注、有效期（默认一年，门店时区当日结束）与声明人。声明是只追加的来源证据；
   **不列任何过敏原的声明表示“该名册下不含任何过敏原”**（数据库要求此类声明绑定名册版本）。新声明取代旧声明；
   配料改版或名册换版后状态显示“需重新声明”。需要 `catalog.allergen.declare`；配方角色可查看（`catalog.allergen.read`）。
3. **配方携带声明**：保存配方时，每个配料行带上该配料当前版本的有效声明（过敏原与声明引用）；**发布时每个配料都必须有仍然有效的声明**，
   否则拒绝并指出行号。食品安全审核人审核的版本内容因此包含过敏原（配方页显示每行过敏原与汇总）。
4. **菜单审核**：接受“已声明不含”的配料；读取的声明必须属于审核所用名册版本（换版后旧声明失效）。顾客端披露从不声称“无过敏原”
   （`allergenFreeClaim: false`，提示询问店员）。
5. 审计只记录数量与来源类型，不写入过敏原名称（审计字段禁止过敏原/健康信息）。

## 页面与接口

- `CMP-ALLERGEN-REVIEW` `/app/compliance/allergens`（名册、配料声明状态）与 `/app/compliance/allergens/{itemId}`（声明表单、历史）；菜单“Allergens”。
- `POST /merchant/compliance/allergens/query|command`（`ApproveRegistry`、`Declare`）。
- 迁移 `2000_015_alter_allergen_declarations`（证据绑定名册、声明内容与声明人、名册条目与声明只追加）、
  `2000_016_alter_recipe_requirement_allergen_declaration`（配方需求记录所用声明）。权限目录 v6。
