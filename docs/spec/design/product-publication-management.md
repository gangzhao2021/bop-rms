# Current Product publication management

WP-2421 milestone92 adds the Catalog-owned recorded management projection for
CAT-PRODUCT-EDIT, Section88, normal Merchant Products edit entry. It joins accepted
public current editor and publication snapshots in one held original transaction,
using the same Product/root revision. Exact selected Store, current Draft owning
content/configuration digests and recorded publication scope/period/schedule
identity/counter support following ordinary command preparation. Nothing grants
current publication, approval or sale eligibility.

CatalogProductPublicationManagementV1 explicitly retains NotEvaluated eligibility
and Incomplete publishValidation. Recorded states and configuration are historical
source values, never current policy or independent approval evidence. There is no
manufactured publication version zero row when a version has no publication yet.
The client may propose a new initial scope under the selected Store; actual current
validation/topology/policy sources must admit every command.

The shortest original source deadline is exclusive; observations are never renewed
by the join. Current native session/Tenant/Brand/Store/Actor and catalog.manage,
product.manage/read, sku.read and history.read permissions are checked before
outer COMMIT with independent current screen/content/history field-purpose holds.
Missing holders or absent runtime composition remains unavailable. Transport accepts
only Product and expected root revision, with ordinary Origin/CSRF/scope controls.
It emits no raw Actor identities, credentials, validation evidence or policy
qualification, and performs no mutation.

No schema, migration, ACL, owning publication lifecycle, System scheduler CAS,
Audit/Outbox or original mutation replay changes. The ordinary frontend controller
and publishing page are following scope. Actual native SQL tests distinguish real
public owning reads/current encrypted isolated-session permissions from synthetic
screen/field declarations; they do not establish real Store/FutureTrigger/UAT.
