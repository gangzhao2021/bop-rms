# Product publication intent controller

WP-2421 milestone94 composes the current owning management read, existing native
User publication transport and current Store capability. CAT-PRODUCT-EDIT remains
the same normal route. Tenant is retained from the already authenticated and
digest-verified owning editor projection, while Brand, Store, Product and root
revision remain exact current context. Context replacement permanently invalidates
the controller and late results cannot affect a different Product or Store.

An explicit new intent rereads current management and compares exact Draft,
recorded versions, scope/period and schedule counters before preparing a single
immutable operation. Its capability and shortest exclusive source lease are
rechecked before dispatch. Recorded content/configuration identities and exact
publication revision come from the owning projection. Initial Validate may use
publication revision zero only because complete recorded coverage has no row;
no zero version object or current qualification is invented. Other actions require
a recorded version. Schedule cancellation/rescheduling bind the recorded Scheduled
identity. The server still supplies current permission, validation, independent
approval, topology, policy, CAS, Audit/Outbox and System activation.

All eight User actions are intent requests, never local eligibility decisions.
Incomplete/NotEvaluated remain visible. A definitive receipt only advances the
expected root for an actual subsequent source refresh. Unknown outcomes lock new
intent and source refresh. Explicit retry rechecks current capability and executes
the exact original prepared request without replacing its root, timestamp, hashes,
operation, schedule or successor. Current denial hides content and retains any
original uncertain operation for restoration. Offline/expiry hides source without
resetting the pending request. Cross-navigation/restart durability is still open.

No private SQL, new fact owner, source DTO, actor selection, synthetic authority,
credentials, logs, permanent storage or automatic retry is introduced. Controller
unit evidence is separate from following ordinary browser/UI verification and92
actual native source/91 actual immutable native command recovery evidence.
