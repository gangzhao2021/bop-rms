# DEC-STORE-REPORTS — 门店销售报表与 CSV 导出（试点）

状态：**Accepted（协调人按商用原则决定，2026-10-14；Owner 可推翻）**。执行工作包：[WP-2423](../work-packages/WP-2423.md)（Q14）。
上位依据：Handoff §38.3（Operational Reporting Projection，强一致判断查询源 Domain）、§88 `RPT-OPS-DASHBOARD`、
"Read Permission never implies Export"、[DEC-COUNTER-PAYMENT-RECORD](counter-payment-record.md)、
[DEC-ORDER-CANCELLATION-PILOT](order-cancellation-pilot.md)、[DEC-PERM-CATALOG](permission-catalog-and-store-roles.md)。

## 问题

日结只能看当天收款/退款合计。单店老板与店长需要：一段营业日的销售汇总（按税种、小费、退款，按收款方式与订单类型）、
按菜品与规格的销量、按小时的销售、小费报表，并能导出 CSV 给会计。收款方式按门店实际：线上卡与门店自有刷卡机，无现金
（Owner 2026-10-13）。

## 决定

1. **口径与日结一致**：一笔销售计入**收款发生的营业日**（线上按服务商收款时间，刷卡机按员工记录的实际收款时间）；
   退款计入**钱退回的营业日**（普通退款按服务商创建时间、补偿退款按服务商确认时间、刷卡机按退款时间）——与日结同一组
   Payment 所有者来源，所以报表与日结到分相同。报表页显示"与日结一致"，不一致时显示两边金额并指向日结（不静默）。
   营业日窗口复用 Q21 定义（`merchant-business-day-window.ts`，日结已改为共用同一实现）。
2. **来源**：只用所有者公开读取，读时组合（apps/api），不新建投影或迁移：Payment `createPostgresStoreSalesPaymentLedger`
   （窗口内收款、窗口结束前的全部已确认退款及其订单/批次，附日结自身合计）；Ordering `createPostgresStoreSalesOrderSource`
   （订单类型、来源渠道与每批次菜品的不可变价格/折扣/税快照）。BI 模块的 Report/Metric Definition 只管元数据与认证，
   明确不负责计算与文件内容，不适用。单店试点量级下按需计算；跨店或长期分析时再建事件投影（Future Trigger）。
3. **金额**：整数分（bigint），不用浮点；每个汇总行都校验"净销售 + 服务费 + 税 + 小费 + 未匹配 = 收款"，不成立即拒答，
   不打印看似合理的错数。批次菜品合计与收款不符时列为"已收款但未匹配菜品"。
4. **报表内容**：①销售汇总：毛销售、折扣、净销售、各税种、小费、收款、退款（分出销售/税/小费）、净收款；按收款方式
   （线上卡 / 门店刷卡机）与订单类型（堂食 / 取餐 / 柜台）拆分；多日时按日。②菜品：按菜品名称（含规格，如"Latte — Large"）
   的售出数量、毛销售、折扣、净销售、退款数量与金额（取消已付款菜品即退款）。选项价格计入菜品。③按门店时间小时。
   ④小费：按营业日与收款方式，含退还的小费。**系统不记录小费归属员工**，页面明确说明，不臆造分配。
5. **退款归属菜品**：普通退款（含员工按菜品取消）用退款请求自身的按菜品分摊；整笔退款（员工整单取消、无法履约、刷卡机退款）
   按批次各菜品"尚未退回"的部分分摊，含剩余小费；对不上时记为"未按菜品拆分"，只计入合计。
6. **未付款即取消**的堂食轮次与取餐单不是销售，不出现。
7. **范围**：1–31 个营业日，结束日不晚于当前营业日；当天显示"Today so far"。
8. **权限**（目录 v12）：`reporting.sales.read` 查看、`reporting.sales.export` 导出（查看不含导出），Owner 与 Store Manager
   持有。导航 "Reports"（`/app/reports/operations`）。读取在同一事务内重新确认会话、门店与权限。
9. **CSV**：服务端生成（受导出权限约束），UTF-8（带 BOM 以便 Excel）、首行表头、每行带 `business_date`、金额为两位小数加
   `currency` 列；不含顾客联系方式、订单号或任何内部编号；以 `= + - @` 开头的文字前加 `'` 防公式注入。四个文件：
   summary / items / hourly / tips。
10. **断网/故障**：报表只读、不影响收银；读不到时页面说明并可重试（记录忙时自动重试 3 次）；刷卡机与日结对账仍以日结页与
    刷卡机批次为准（见运维手册 Q9）。

## 已知限制

- 导出不写审计记录（文件无个人数据）；如需导出留痕，另加 Audit。
- 小费按收款记录，无员工归属；如门店要按员工分小费，需先记录"谁服务了这一单"（未在范围内）。
- 现金不支持（Owner 决定）。
