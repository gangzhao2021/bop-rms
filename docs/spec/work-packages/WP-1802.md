## Resolved contract and hard gate

WP-1027 exposes a bounded Menu summary projection and explicit Submit Review, Approve, Publish and
Archive API actions. That summary does not include the snapshot digest, effective period,
validation/approval evidence or safe Brand reference required to issue those Commands from the
current browser route. No accepted browser BFF supplies those facts with the WP-1800 CSRF/session
contract. This WP therefore must not infer them or offer a caller-selected target state.

The implementation adds canonical list and builder routes, strict closed parsers and injectable
browser clients. The default runtime is unavailable and performs no request. List fields absent
from `catalog_menu_management_v1` are explicitly labelled unavailable. The Builder renders an
authorized Section tree, keyboard-visible move alternatives, validation rail and contextual
publish workflow when an owning adapter is injected; every authoring/lifecycle button remains
disabled until a closed browser Command contract can carry authoritative digest, evidence,
effective period, CSRF, UUIDv7 idempotency and Expected Version.
