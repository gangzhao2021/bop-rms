## Purpose and acceptance

Close the Phase 1 Pricing critical path with synthetic, deterministic recalculation evidence:

1. the exact same input and pinned versions reproduce the exact Quote contract result;
2. Quote identity changes do not change calculation evidence;
3. an expired Quote recalculated from unchanged authoritative versions remains unchanged;
4. a new Price Book version recalculates from its exact amount and retains old/new evidence;
5. a new Tax configuration version recalculates exact minor-unit rounding and retains old/new
   evidence;
6. representative minor-unit boundaries remain deterministic without binary floating point; and
7. changed Cart Version/input uses a fresh Quote path and cannot be smuggled through same-Cart
   expired requote.

## Boundaries, risks and rollback

- This is a test-suite WP. It does not change production Pricing, API, database, Event or UI code.
- `SPIKE-1106` owns real Canadian Pilot Jurisdiction verification. No real rate, legal conclusion,
  Provider result, professional approval or External Evidence is invented.
- Promotion, Fee, Cart persistence/mutation, Checkout confirmation, Order, Payment, scheduler and
  immediate tax/legal/obvious-error invalidation remain outside this WP.
- Fixtures are synthetic and version-pinned. They prove deterministic mechanics only, not tax
  correctness for a live jurisdiction.
- Rollback is a reviewed Git revert of the tests, brief and acceptance-script entry. There is no
  data or external rollback.
