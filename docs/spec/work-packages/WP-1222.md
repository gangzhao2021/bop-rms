## Purpose and boundary

Implement the pure Ordering-owned transaction snapshot boundary for one validated Cart version.
The builder copies, runtime-validates and deeply freezes every line's Catalog identity/display and
version evidence, exact selected Option configuration, Cart attribution/note, final bigint Money,
Price resolution and Tax rule/rate/amount evidence. It never recalculates Pricing or Tax and never
queries current Catalog state, so later source changes cannot rewrite Order history.

## Contract and acceptance criteria

1. A closed input must contain one exact server-owned Active Cart/version, current WP-1220 Checkout
   evidence and one Catalog/Pricing snapshot line for every validated Cart Item. The exact Checkout
   expiry instant is closed.
2. Brand, Store, Cart/version, Sellable, Product/Menu versions, Quote reference/input digest,
   quantity and line identity must agree across all authorities. Missing, extra, duplicate or
   drifted lines fail closed.
3. Catalog snapshots preserve stable snapshot reference/digest, Product/SKU/version, localized
   names, unit, Tax classification and selected Options with Binding/Option Set versions. Selected
   Option reference and quantity must exactly match the Cart and accepted rule evidence.
4. Pricing snapshots preserve Currency metadata, final unit/subtotal/discount/tax/fee/total bigint
   Money, Price Book/version/digest/entry, Tax Configuration/version/digest and every final Tax
   component rule/digest/rate/treatment/rounding/order/amount. Currency, line arithmetic, Price unit
   and Tax component totals are validated, never recalculated.
5. Customer Note and actor/participant attribution are copied only from the server-owned Cart.
   They are classified as indirect/personal and possible health data and must not enter logs, URLs,
   analytics, screenshots or non-synthetic fixtures.
6. The output is deeply frozen and closed. It contains no Payment, credential, contact, Provider,
   capacity, Kitchen or current-configuration query field.
7. Frozen install, Ordering regression, retained isolated PostgreSQL, affected static/build and
   architecture checks, scope/security review and exact-head/exact-main CI pass before Done.
