## Resolved test boundary

WP-2028 composes the accepted Notification request, receipt renderer, one-time resume token, Customer
fragment cleanup and authenticated SES/SNS event contracts in one deterministic synthetic scenario.
Duplicate logical registration converges at the Unit of Work idempotency boundary. Plaintext resume
material exists only in worker memory and the canonical URL fragment; persistence, operational
summaries and normalized Provider events contain only opaque references or hashes. Browser recovery
cleans the fragment before exchange, consumption is one-time, and a duplicate hard-bounce event
applies one immediate suppression/case intent without retaining the destination or raw payload.

A Customer who supplied no contact receives no email route and no resume token. The already
authorized in-session receipt remains available, but loss of that Guest Session has no remote
recovery path. This is an intentional fail-closed product rule, not a synthetic recovery channel.
The repository still has no accepted production SES adapter/composition or external Provider
evidence; the scenario does not claim a real email send.
