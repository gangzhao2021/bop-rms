# WP-2293 - Immutable Guest Binding Store Commands

## Authority and scope

Baseline0fd8df1; branch codex/wp-2293-binding-store-command-capture. Continuous bounded
local implementation and verified local commits remain authorized. Composite Sections0-97,
WP-2235 transactional binding store and WP-2292 closed pure transitions govern.

The existing writer parses some fields before awaiting, but reads proof, owner evidence and
CSRF hash from caller objects after database awaits. Its nested Session store also receives
original mutable constructor scope. Reproduce malformed and in-flight mutation behavior.

## Acceptance

Capture and parse exact acknowledge/activate/complete commands, including all nested proof
and owner evidence, before opening transactions. Reject malformed/accessor/symbol/hidden
and non-plain inputs without executing getters or opening transactions. Capture constructor
Brand/Store scope and use that immutable scope for nested Identity owner stores.

Current authority, complete proof, exact owner scope, time and stored revision remain checked
under the existing transaction/locks. In-flight changes to caller proof, owner evidence, CSRF
or original constructor scope must not alter the submitted operation. Preserve public Audit,
rollback, append-only history, expiry, retry and Pickup policy. Errors stay fresh and bounded.
