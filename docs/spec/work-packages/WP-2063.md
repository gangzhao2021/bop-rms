## Resolved local boundary

WP-2063 adds a deterministic fail-closed workload-stack contract covering the pinned CDK toolchain,
environment isolation, two-AZ production network, private ECS, isolated RDS, private S3, separated
KMS/Secrets, required VPC endpoints, firewalled allowlisted egress and distinct least-privilege task
roles. The contract prohibits public tasks/RDS, ordinary ECS Exec/SSH/debug, plaintext secrets,
shared IAM user keys and application root use.

No CDK dependency or synthetic stack is introduced because the repository has no accepted CDK
package/bootstrap baseline and no real account/Region evidence. The local contract must pass before a
future authorized synth/deploy can claim conformance.
