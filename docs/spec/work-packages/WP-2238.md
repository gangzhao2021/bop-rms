# WP-2238 - Atomic Cart Lifecycle Persistence

## Authority and scope

Owner authorizes sustained implementation and verified local commits. Baseline fee939b, branch
codex/wp-2238-cart-lifecycle-store. WP-1204 and WP-2233 govern authorized Customer abandonment,
System expiry, immutable terminal history, version-pinned deadlines and 24-hour stable retries.
Composite authority is unchanged. Only Ordering owns the Cart and lifecycle operation records.

Implement one scoped owner-local reader/writer over existing Cart, Cart Line and lifecycle operation
tables. The existing service authorizes before read/write; the adapter verifies exact transition,
version, operation intent and bounded Audit, then commits Cart, history and public Audit atomically.
Concurrent same-key commands return the original persisted result at its original time; service
verification must accept that canonical winner while rejecting substitutions. Different commands
at one version conflict. No Item, Quote, creator or policy history is rewritten.
