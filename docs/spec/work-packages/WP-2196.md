## Acceptance contract

1. An Export Job pins source Screen/View ID, Tenant/Brand/optional Store scope, normalized filter and
   selected-column snapshot digests, source Projection/checkpoint, format, classification, purpose,
   requester and expiry policy. Client-supplied counts, scope or permission never grant authority.
2. v0.1 allows asynchronous UTF-8 CSV or canonical JSON only. XLSX/XLSM, macros, PDF, remote URL
   imports and unrestricted raw-text export fail closed. Row count is at most 100,000, artifact size
   at most 100 MiB and expiry at most 24 hours from generation.
3. Source execution reauthorizes Tenant, Store, Actor, purpose, export permission, every selected
   field and row scope against the pinned public source contract. PII/Restricted export additionally
   requires accepted recent step-up/support evidence; unavailable evidence blocks rather than being
   fabricated.
4. CSV serialization is streaming and formula-safe for text cells beginning with `=`, `+`, `-`,
   `@`, tab or carriage return. Typed numeric values remain numeric; canonical JSON preserves exact
   raw text where required.
5. Queue, start, complete, fail, cancel and revoke use exact permissions, expected version,
   idempotency and atomic Audit. Cancellation bounds work; completion cannot succeed after cancel or
   revoke and cannot invent an object/checksum/encryption result.
6. An encrypted artifact reference is immutable and never exposed as an unrestricted object ID or
   reusable presigned URL. A fresh application grant is atomically consumed once; the BFF streams
   `attachment` with `Cache-Control: no-store`. Expired, revoked, consumed or scope-drifted grants
   fail closed and every attempt records minimized append-only evidence.
7. Export Job, state, artifact, grant, download and revocation histories are append-only with forced
   Brand/optional-Store RLS. Object bytes remain with the approved private object service and are
   not stored in BI tables, Audit, logs, fixtures or URLs.
8. `EXPORT-JOB-LIST` `/app/exports` exposes source, scope, safe filter summary, classification,
   status, row count, expiry and requester; it supports type/status/requester/date filters and
   authorized create, cancel, one-time download and revoke actions with complete responsive,
   accessible loading/empty/denied/not-found/offline/stale/conflict/expired states.
9. This WP creates no real export, PII, source snapshot, S3 object, KMS key, application grant,
   download, approval, Support evidence or external action.
