# WP-2226 — Lossless Quote Snapshot Codec

## Authority and scope

Baseline `WP-2225@2a9444b`; branch `codex/wp-2226`. Continued local implementation and verified
local commits are authorized. Composite Handoff 0.5.3 Sections 21, 27, 52, 87, 92–97 and
WP-1103–1105 govern the existing immutable Quote output. This bounded prerequisite implements
validation and a versioned JSON-compatible codec for that output before adding database storage.

## Acceptance

1. Round-trip every existing Quote field, nested Price/Tax resolution and calculation explanation,
   Currency exponent, references/digests, timestamps and array order. Monetary bigint values use
   canonical decimal strings; values above JavaScript safe integers remain exact.
2. Reject extra/missing fields, unsafe objects/accessors, malformed references, currencies, amounts,
   timestamps, unsupported envelope versions, inconsistent totals and changed tax explanations.
   Validate without querying current Catalog, Price Book or Tax Configuration sources.
3. Return immutable independent snapshots. Preserve the accepted Phase-1 calculation semantics:
   exclusive taxes, zero Discount/Fee and empty Promotion/warning/blocker results. Future nonzero
   adjustments or new fields require an explicit codec revision, not silent interpretation.
4. Synthetic tests cover multi-line order, compound tax, precision, malformed/tampered evidence,
   immutable results and error redaction. Frozen install, affected Pricing checks and full local
   `DOCKER_HOST=unix:///Users/ryanzhao/.colima/default/docker.sock TMPDIR=/private/tmp CI=true pnpm verify`
   pass before a completion claim.
