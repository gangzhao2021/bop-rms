## Contract and ownership

The side-effect-free Query requires trusted server authorization for exact `reporting.read`, an
explicit `OperationalReporting` purpose, Tenant / Brand / Store / Actor scope,
Business Date, IANA timezone, CAD currency and authorized channel / order-type filters. It composes
only the accepted public operational Projection contracts. Every result exposes source checkpoint,
data-as-of time, freshness, completeness and unavailable gaps. Missing collaborating data produces
`null` KPI groups rather than misleading zero. CAD values remain base-10 minor-unit strings.

The dashboard is not a source of transaction truth and exposes no mutation. Full Screen rendering,
saved views, drill authorization, export / schedule, persistence, API and realtime composition
remain WP-2160 or later implementation evidence and are unavailable rather than represented by a
synthetic connected page.
