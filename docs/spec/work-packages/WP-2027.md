## Resolved test boundary

WP-2027 composes the accepted Catalog and Kitchen public contracts in one deterministic synthetic
scenario. Catalog must block `Unverified` or `Conflicting` evidence and deterministically propagate
base plus enabled-Option allergen classifications without an allergen-free claim. A structured
Staff review uses only the controlled allergen references and exact configuration/policy/Recipe
versions. `CannotSafelyAccommodate`, expiry or configuration drift keeps the downstream payment
eligibility gate closed; only an exact current `Accepted` review opens the synthetic boundary.

Kitchen then requires distinct named-operator `BeforeStart` and `BeforeHandoff` acknowledgements,
retains a persistent high-priority non-color cue and links a mismatch to both a Compliance Case and
Catalog availability Kill Switch action. The scenario does not create a public Checkout/Payment
route, persist Customer medical narrative or claim real policy, supplier, Store, staff or Payment
evidence. Production Checkout/Payment composition remains unavailable and unclaimed.
