## Scope and acceptance

Implement the Dining-owned pure consumeDiningIdentityAdmission transition. Parse closed input
and owned immutable records; require exact expected admission and Session versions, Active Session,
Active Participant belonging to that Session, and current eligible Table/assignment evidence.
Admission Store/Table/assignment/Session/Participant must match the current facts; original Join
issuance equals Participant joinedAt and follows Session start. Evidence observation must equal
the requested canonical UTC instant. Future issuance or stale assignment is unavailable.

Only Active/version1 admission with null consumedAt may become Consumed/version2. Preserve every
original Join identity and immutable field; set consumedAt to the explicit observation. Repeated
consumption does not become an implicit grant. Return a new frozen record; never mutate caller
objects or invoke accessors. Malformed input uses owned invalid-input errors; ineligible current
facts use unavailable errors; valid-but-stale expected versions use version-conflict errors.

This is a pure state transition, not Guest authentication or a persistence lease. A later service
must verify the current exact Guest against original Join history, and a durable owner writer must
re-read current facts under shared locks and record consume-operation recovery atomically. Identity
continues to own rotation. Public Table mapping and evidence validity require explicit composition;
no public/internal Table identity equivalence or admission TTL is inferred.
