## Resolved contract and hard gate

WP-1707 owns only the Customer PWA connectivity shell and foreground recovery language. WP-1708
owns Workbox, Cache Storage, request routing, NetworkOnly enforcement and safe Service Worker
updates. This package installs no Service Worker, creates no cache, claims no offline Menu snapshot
and changes no HTTP adapter.

The shell exposes three page-memory states: Online, Offline and Restored-after-offline. Offline copy
makes transaction and identity activity read-only/unavailable and explicitly says nothing will run
in the background. Restored copy requires the Customer to review current state and use each Screen's
explicit action; the connectivity transition invokes no client load, retry, create, submit,
Payment observation or Command. The restored notice is dismissible and is announced without
stealing focus.

Existing controller rules remain authoritative: unknown Payment outcome retains the same operation
reference and only the explicit retry action may observe/retry it; Cart/Checkout/Payment/Order
Status/Pickup controllers do nothing on `setOnline(true)`. Private data remains page-memory only and
is never promoted into an offline shell.
