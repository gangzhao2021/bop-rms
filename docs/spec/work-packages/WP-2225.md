## Ownership and implementation

Ordering owns Add/Update/Remove Item operation records and immutable Quote attachments. Identity
continues to authorize the current Session; Pricing remains a public injected port. Scope,
Guest/Participant, expected version, operation key, content and Audit validation stay explicit.
No private foreign access, schema, public command field or financial calculation changes.

On retry, compare the parsed business intent using the original operation's persisted observation
time (`occurredAt` or `attachedAt`), rather than the retry's newly observed server time. Continue
using the retry time for current authorization, Audit evidence and exact 24-hour expiry. New
operations retain the existing fingerprint encoding, so existing append-only records need neither
rewriting nor a schema migration. Changed business input remains an idempotency conflict.
