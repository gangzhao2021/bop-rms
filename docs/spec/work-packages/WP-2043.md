## Resolved test boundary

WP-2043 promotes the accepted centralized structured-logging redaction matrix to a dedicated
security gate across Observability, API and Worker. The closed logger schema admits only bounded
technical fields and trusted correlation references. Unknown fields, accessors and raw errors
disable the leaking path and emit only a constant safe signal. HTTP path/query/header/Cookie/
Authorization, contact, Token, Payment, allergy/health, SQL/bind and free-text canaries remain
absent from serialized output.

This WP reuses the single accepted redactor rather than creating a divergent filter. It adds no
new log field, PII, identifier, sink, retention rule, CloudWatch/ADOT resource or production result.
