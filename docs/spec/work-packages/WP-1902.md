## Contract and ownership

Kitchen remains sole owner of Ticket/Work Item lifecycle, quantities, structured safety cue,
exception and Order-item Ready evidence. Existing `kitchen_work_queue_v1` remains the Kitchen-owned
board projection and is not rewritten. This WP adds a distinct operational summary in the technical
Projection module using only strict Store/station-scoped public snapshots.

Status and quantity invariants are closed: Completed requires exact completed == required plus a
source completion instant; Ready time is accepted only on Completed source evidence; InProgress
requires a start instant. Safety is a bounded non-medical cue, not free text. Client state or elapsed
time cannot create acceptance, start, completion or ready truth. Every generation exposes explicit
scope, Business Date, checkpoint, as-of/projected/rebuilt time, initialized-empty and a 2-second
Fresh/Stale target. Shadow persistence/version switching remains WP-1904.
