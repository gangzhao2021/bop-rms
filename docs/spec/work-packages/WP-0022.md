## Goal and exact objects

Create one default-denied `platform_helpers` technical schema and only these objects：

- `is_uuid_v7(uuid)` and domain `uuid_v7`
- domains `amount_minor` and `currency_code`
- `is_iana_time_zone(text)` and domains `iana_time_zone`、`local_date`、`local_time`
- `current_brand_id()` and `current_store_id()` transaction-local context readers

The dedicated external migration role owns every object。All functions are invoker-rights with fixed safe resolution；PUBLIC has no schema / type / function privilege；no runtime receives an advance grant。No object generates IDs、calculates / rounds Money、resolves Business Date、authorizes a request、validates Brand–Store membership or implements table RLS。
