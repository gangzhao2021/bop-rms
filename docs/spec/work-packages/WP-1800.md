## Closed implementation contract

The same-origin Merchant BFF remains the only browser authentication boundary. Its no-store
bootstrap returns the Session-bound CSRF credential plus a closed, permission-trimmed workspace
snapshot. Unauthenticated or expired Session state exposes only a same-origin sign-in action. The
browser never receives Provider tokens or encrypted Session material.

The workspace snapshot identifies the selected Brand/Store by safe display labels and contains
only Stores already authorized for the Actor. A switch is a CSRF-protected POST; the API delegates
authorization and expected-version Session rotation to the accepted WP-0109 service, sets the new
`__Host-` Cookie and returns a fresh permission-trimmed snapshot. The UI cannot manufacture an
arbitrary status or treat selection as authority.

`HOME-OVERVIEW` renders selected scope, Store status, Business Date and explicit availability of
today summary, open tasks/exceptions and system/Provider health. WP-1905 owns real dashboard
projection values, so unavailable fields remain visibly unavailable in WP-1800 rather than using
synthetic business facts. Required failure, stale, conflict and offline states are non-color-only.

## Acceptance and verification

- `/app` starts with a no-store Session bootstrap and shows sign-in without leaking failure detail
  when authentication is unavailable;
- bootstrap and Store switch reject open/malformed workspace data, cross-site request context,
  missing CSRF and arbitrary non-authorized Store selection;
- successful switch uses POST, applies the rotated `__Host-bop-merchant` Cookie server-side and
  replaces the complete client snapshot without optimistic authority;
- `HOME-OVERVIEW` exposes the full mandatory field groups with explicit WP-1905 unavailability,
  permission-trimmed navigation and responsive/keyboard/screen-reader semantics;
- API and Merchant Web tests plus affected format/lint/typecheck/build and Screen Registry checks
  pass locally; real Cognito, Store and dashboard evidence remains unclaimed.
