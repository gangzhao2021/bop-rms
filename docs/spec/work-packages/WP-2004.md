## Contract and ownership

The existing Import Boundary test now validates the complete synchronous Module dependency graph,
not only source import sites. Every Manifest dependency must resolve to a discovered exact Module and
must have an exact internal runtime dependency in `package.json`; every internal runtime dependency
must be declared by the Manifest. Strongly connected components with more than one Module fail as a
synchronous dependency cycle.

The pre-existing gates continue to enforce canonical identity, BOP-to-RMS prohibition, public export
maps, no private/cross-Module relative imports, exact declared dependencies and deterministic sorted
diagnostics. No Module dependency or business implementation is changed by this WP.
