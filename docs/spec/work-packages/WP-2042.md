## Resolved local boundary

WP-2042 freezes the ten accepted default endpoint-class abuse budgets as a versioned,
machine-validated security baseline. It retains the WAF/application split, fail-open/fail-closed
rules, trusted-proxy/keyed-hash privacy boundary and retention constraints. Lowering any protected
default requires Security approval and an expiring risk record.

Atomic application enforcement and `security.abuse_bucket` remain WP-2048. This WP does not add an
in-memory authority, Redis, client-IP parser, database table, WAF rule, production configuration or
load result. Passing the baseline validator proves configuration integrity, not live enforcement.
