## Acceptance contract

1. Temperature Reading records pin Tenant/Brand/optional Store, target Location/Equipment/Food
   scope, Monitoring Policy Version, measurement/unit codes, exact-decimal value when observed,
   measured/captured instants, Manual/Sensor/Imported method, Actor/Device, Threshold Result and
   calibration reference. Each monitoring stream has an append-only sequence and idempotency key.
2. Threshold Result is closed to `WithinRange | BelowRange | AboveRange | Missing | Unverified |
DeviceFault`. Missing/DeviceFault carries no value; device offline never implies normal or
   abnormal. A manual correction is a new Reading linked to a prior Reading in the same exact
   stream; the source Reading is never overwritten.
3. Temperature Excursion records have stable identity and immutable revisions, exact Severity,
   start/end, exact-decimal deviation bounds, affected scope, detection source, linked Reading,
   owning-Domain containment/disposition references and coded root-cause/resolution facts. Initial
   detection publishes `TemperatureExcursionDetected`; no stock disposal or release is inferred.
4. Cleaning records pin Schedule/Task, Cleaning Policy and Procedure Versions, area/equipment scope,
   assignee/due timezone, performer/times, method/chemical/concentration snapshot, Evidence
   references, Exception, verification and immutable revision history.
5. Cleaning status is closed to `Scheduled | InProgress | Completed | CannotComplete | Missed |
VerificationFailed | Verified | Cancelled`. Completion is not Verification. Failed Verification
   publishes `CleaningVerificationFailed`; missed work escalates but never fabricates completion.
6. Chemical Result is closed to `NotRequired | WithinRequirement | OutsideRequirement | Unverified`.
   OutsideRequirement requires a Safety Review reference. Policy-required independent Verification
   rejects the performer as sole verifier.
7. Every mutation revalidates Tenant Context, trained Actor, purpose, action-specific Permission,
   exact scope, expected sequence/revision, idempotency and safe Audit evidence. Dependency
   uncertainty, stale version, cross-scope source, binary-float input and restricted content fail
   closed.
8. `CMP-TEMP-LOG` and `CMP-CLEANING` expose Section 88 fields, filters, permission-gated actions and
   explicit loading/denied/offline/stale/conflict/error/empty states. UI contracts accept only safe
   codes/references/counts/exact decimals and never raw Evidence, food/employee narrative, device
   secret, chemical instructions or arbitrary free text/URLs.
