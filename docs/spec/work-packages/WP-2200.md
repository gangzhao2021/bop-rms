## Acceptance contract

1. The preview is disabled by default and can be enabled only when Vite is running in development
   mode with the exact local environment flag `VITE_BOP_LOCAL_DEMO=1`.
2. When enabled, the accepted Store, Menu, Order, Kitchen, Compliance dashboard and Support Case
   routes use deterministic synthetic fixtures through their existing strict parsers and render
   primary plus linked detail states without a network request.
3. The preview is visibly labelled as synthetic/read-only; authoring controls remain disabled and
   no success, publication, permission or external evidence is implied.
4. Production builds and unflagged development retain the fail-closed
   `unavailableStoreAdminClient` behavior.
5. The preview contains no credentials, tokens, payment data, health/allergy facts, real addresses,
   real people or unnecessary PII. Support data is explicitly `NonProduction`, grants no access and
   enables no action.
6. `pnpm demo:merchant` starts the exact local showcase on `127.0.0.1:5173`; the normal build and
   unflagged startup retain the accepted sign-in and unavailable states.
7. `HOME-OVERVIEW` preserves its canonical route and Screen ID, presents one synthetic authorized
   Store context, exposes only existing permission-labelled navigation contracts and clearly
   separates Merchant operations from the synthetic Platform Support entry.
