## Resolved contract and hard gate

Section 88 maps the Store screens to permission-trimmed `organization_*_v1` Query facts and
server Commands. The machine Screen Registry omitted WP-1801/WP-2192 from `STORE-LIST`; this WP
repairs that derived mapping to match the accepted Section 88 row.

WP-2192 owns real Store configuration projection, persistence and authoring Commands. WP-1801 does
not invent them. It adds canonical routes, closed parsers and injected browser clients for the
minimum Screen package. The default runtime is explicitly unavailable and performs no network
request until the owning API contract is integrated.

`STORE-LIST` admits only authorized summaries and exposes code, name, lifecycle, timezone, address
summary, service modes, today-hours status, live-gate status, configuration source and freshness,
with bounded client filtering over the already admitted list. `STORE-DETAIL` renders every required
section and never treats an unavailable collaborating source as empty/zero. `STORE-SETUP` renders
the fixed identity → address/timezone → service modes → hours → tax/payment refs → capacity →
contacts → review sequence, Expected Version and evidence gate. Draft save/validate/publish intents
remain disabled without an injected server contract; publish can never bypass required evidence.
