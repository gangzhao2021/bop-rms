## Acceptance contract

1. Production builds exclude `merchant-demo` and its synthetic fixtures from every emitted
   JavaScript asset, including when `VITE_BOP_LOCAL_DEMO=1` is present at build time.
2. Production and unflagged development retain the existing unavailable clients and signed-out
   Merchant workspace behavior.
3. Exact-flag development continues to load the same deterministic, visibly labelled, read-only
   Store, Menu, Order, Kitchen, Compliance, Support and `HOME-OVERVIEW` preview.
4. Demo loading performs no network request and introduces no credential, persistence, permission,
   business fact, external evidence or production activation.
5. Load failure fails closed to the normal unavailable clients and never renders partial synthetic
   authority.
