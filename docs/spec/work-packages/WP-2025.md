## Resolved test boundary

WP-2025 promotes the accepted WP-1904 rebuild contract into one stateful failure/recovery scenario.
The first attempt writes a shadow generation but fails closed on validation checkpoint mismatch. It
must abandon only that shadow and retain the active generation. A retry of the same authorized
Command may build a fresh shadow from the same fixed checkpoint, validate it and atomically replace
the expected active generation. A later replay returns the stored completion without opening a
third shadow.

The scenario uses a deterministic in-memory persistence adapter around the public Projection
contract. It does not claim durable `platform_projection` tables, Worker composition, production
Event replay, performance or external recovery evidence.
