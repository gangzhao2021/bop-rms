## Contract and ownership

The Contract package owns a deterministic OpenAPI 3.1 artifact for only the currently composed
`/api/v1` Public and Merchant REST routes. BFF, Session, health/readiness, SSE, webhook and
acceptance-only routes are different transport classes and are excluded. Zod remains runtime schema
source; the generated artifact is checked byte-for-byte and validated with Swagger Parser. Stable
operation IDs, path references, Error Contract responses and required idempotency / expected-version
headers are contract-tested. Examples are synthetic and contain no real identifier or sensitive fact.

Planned but uncomposed Handoff endpoints are not advertised. Full request/response DTO coverage,
example execution and backward-compatibility diff remain WP-2001–2002 or later owning API WPs.

## Acceptance and verification

- deterministic generation and byte-drift check pass;
- OpenAPI 3.1 schema and all references validate;
- operation IDs are unique and documented paths equal the bounded composed-route catalog;
- mutations declare idempotency and, except create, expected-version headers;
- BFF/SSE/health/internal routes and real/sensitive examples remain excluded;
- contract format/lint/typecheck/test/build and root architecture gates pass;
- live API example execution and compatibility evidence remain unavailable and unclaimed.
