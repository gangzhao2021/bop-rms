branch codex/wp-2241-cart-read. Composite authority is unchanged. WP-1204/1205 and

Implement an Ordering application reader using public Identity background resolution and the
Ordering active-binding query port. Resolve current live credentials before any Cart access;
resolve again before returning restricted data. Scope and immutable Pickup creator must match.

arbitrary aggregate. Unbound and other Cart references both return null. DineIn remains unsupported.

observation never updates Cart, Session activity, history or Audit. Clock belongs to composition.
