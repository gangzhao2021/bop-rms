## Resolved local boundary

WP-2064 adds a deterministic fail-closed deployment contract for claim-scoped GitHub OIDC,
immutable scanned ECR digest promotion, CodeDeploy ECS blue/green canary rollout, dedicated one-shot
database migration and readiness/drain behavior. It composes with WP-2050 so staging and production
must promote one signed scanned digest rather than rebuild it.

No workflow, repository identity, role ARN, registry digest, credential, deployment or migration is
created or claimed. GitHub steps are explicitly skipped; synthetic policy evidence is local only.
