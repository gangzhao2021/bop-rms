## Purpose

Create one immutable, reproducible, expiring Price Quote from server-authoritative Cart/Catalog,
Price Book and Tax Configuration facts. Expose the Phase-1 REST command without trusting any
client-supplied amount.

## Contract

- `POST /api/v1/carts/{cartId}/quote` accepts a closed `{ cartVersion }` body plus exact Customer
  Session and Idempotency headers.
- The injected Pricing Application port reloads Cart/configuration facts and owns scope,
  idempotency, version and invariant decisions.
- A successful `201` response contains Quote ID/version, Currency, Subtotal, Discount, Tax, Fee,
  Total, line breakdown, Price/Tax evidence, Promotion references, expiry, warnings and blockers.
- Money is serialized as decimal minor-unit strings; JavaScript floating point never enters the
  calculation or response contract.

## Boundaries

- WP-1103 supports the accepted Pilot exclusive-tax path. Inclusive configuration fails closed
  until an accepted composition rule is supplied; WP-1101 still retains inclusive rule semantics.
- Discount, Fee and Promotion are explicit zero/empty results. No behavior or evidence is invented.
- WP-1104 owns expiry/requote and price-increase reconfirmation. WP-1200+ owns Cart persistence and
  mutation. Order/Payment/UI/Event are absent.
- Customer Session validation and idempotency storage are Application/platform ports; the public
  API never grants scope from client Brand/Store headers.
