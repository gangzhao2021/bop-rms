# WP-2253 - Bounded Foreground Checkout Quote Responses

## Authority and scope

Owner authorizes continuing bounded implementation and verified local commits. Baseline7c703a4;
branch codex/wp-2253-quote-transport. Composite Sections0–97, WP-1703 and WP-2248/2249/2252
retain explicit foreground requests, exact public Quote validation, private Session/CSRF state,
server-owned monetary facts and uncertain mutation intent. CUST-CHECKOUT route/permission,
fields, page states and accessibility are unchanged. No Payment or Provider action is introduced.

Quote requests currently bound only response headers, accept an unbounded JSON body, and can
return an old Quote after Session replacement. Apply one15-second deadline across headers and
streamed body, with a16MiB actual-byte ceiling matching the existing Cart transport. Race the
complete operation against cancellation even if fetch ignores AbortSignal; cancel late bodies,
release stream locks and remove the timer on every outcome. Reject redirects, malformed UTF-8/JSON
and unavailable/malformed command responses with network_unknown, preserving possible commit.
Retain only closed, matching HTTP400/409/422 error contracts as definitive bounded rejections;
unknown/unavailable/mismatched status remains uncertain. Use same-origin credentials, cors mode,
no-store, redirect error and no-referrer; never send money or private identifiers in URLs.

Capture the existing opaque in-memory Session context and reject superseded headers, body,
errors or final Quote delivery. Snapshot the requested Cart reference/version before any await;
validate the public Quote against that original version without mutating caller data or calculating
money. Do not clear/replace CSRF in this transport. Preserve valid current responses and stable
operation headers. No automatic retry, storage, background work or shared fetch-helper rewrite.

Checkout controller orchestration/load races, default App/runtime wiring, live pricing/Provider
readiness, cross-document/reload recovery and shared DineIn remain separate work.
