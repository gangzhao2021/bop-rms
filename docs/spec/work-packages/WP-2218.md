## Problem and bounded implementation

The lease allocator currently treats the system temporary parent's alias as if the lease directory
itself were a symlink. Resolve only the existing OS temporary parent before constructing the lease
root. Keep the lease directory's own lstat, realpath equality, ownership and owner-only permissions
checks unchanged. Do not follow or repair a malicious lease-directory link or insecure directory.

## Acceptance and exact allowlist

1. Full isolated PostgreSQL acceptance succeeds with default macOS TMPDIR and with an explicit
   portable symlink alias to a synthetic temporary parent; no manual TMPDIR override is required.
2. An actual lease-directory symlink and a group/world-accessible lease directory are rejected with
   the existing ISOLATED_DB_LEASE_FAILED diagnostic, including beneath an aliased parent.
3. Retain parallel allocation, every failure injection, timeout, SIGINT/SIGTERM, redaction and
   cleanup. New temporary-path cases use disposable parents and clean only owned paths/resources.
4. Frozen install, affected database checks/integration, root/full verify with default TMPDIR,
   final scope/security review and exact-head/main CI pass before another WP begins.
