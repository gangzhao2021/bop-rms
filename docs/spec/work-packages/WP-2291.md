## Acceptance

actual Dining Start/Join/consume and Identity bindDining/rotate. Test-only explicit public
Table mapping and evidence validity are never claimed as production facts or policy.

Prove one consumed admission and one rotated DiningBound session, stable Participant,

changed-operation denial. Inject failure between Dining commit and Identity rotate;
old Identity must remain active and the same operation must recover without another
Dining consume/Audit. Inject lost Identity acknowledgement and recover its exact result.
Use current Identity-owned reads in the test Guest authority adapter; reject another Guest.
Neither domain may read or mutate the other's private storage from production code.
