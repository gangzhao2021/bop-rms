## Resolved local boundary

WP-2050 adds a deterministic, fail-closed validator for a release evidence bundle. The bundle must
bind the trusted source and builder, immutable base and result digests, SPDX SBOM, in-toto
provenance, dependency/secret/SAST/container/IaC/DAST results, license notices and cosign
verification to one release image. Staging and production must promote that same digest.

The local tests use conspicuously synthetic digests and never claim a real build, scan, signature,
KMS key, ECR setting, GitHub identity or deployment. Producing and retaining the real bundle is an
External Evidence gate owned by the release environment.
