# WP-2292 - Closed Guest Binding Transition Commands

## Authority and scope

Baseline63ceb72; branch codex/wp-2292-binding-command-boundary. Continuous bounded local
implementation and verified commits remain authorized. Composite Sections0-97, WP-2234
Guest binding preparation and the existing closed Identity contracts govern.

Static review found outer prepare/acknowledge/activate/complete inputs are read directly,
while nested persisted records are closed. Prepare spreads the caller before overwriting
state fields; supplied accessors may execute. Possession/completion comparisons accept
truthy provider values rather than requiring exact boolean true. Reproduce before fixing.

## Acceptance

All four pure transition command objects must reject extra/missing/symbol/hidden/accessor,
non-plain/array/null inputs before reading caller properties. Prepare must accept only its
seven declared fields, never caller-supplied lifecycle fields. Acknowledge/activate/complete
must capture their exact declared command shape and continue validating nested records.
Require exact true for every Session/CSRF/recovery hash comparison; false, truthy nonboolean,
undefined and thrown providers fail with fresh bounded GuestSessionError. No input mutation.
Preserve existing successful transitions, original retry time, current authority, Pickup-only
scope, expiry limits, stored record/hash bytes and candidate-possession requirements.
