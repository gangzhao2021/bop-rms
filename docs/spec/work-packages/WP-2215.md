   loopback HTTPS and uses the existing Entry handler, Domain composition, real credential

   admission inputs remain explicitly synthetic fixtures; no production key or external service is used.

   failure UI and no success state. Verify Origin/Fetch Metadata enforcement, no credential in
   the URL or DOM, no cookie access through document.cookie, and no unrelated external requests.

   never tracked or printed. Browser traces, videos and screenshots are disabled. Browser,
   HTTP/HTTPS listeners, pools, temporary files and database/role resources are cleaned after
   success and failure. Production application configuration and trust checks are not weakened.

   into the existing CI browser step after Chromium installation. No dependency version is
   upgraded; reuse the pinned Playwright version already present in this repository.
8. The status ledger records the remaining ordered increments and their concrete prerequisites:
