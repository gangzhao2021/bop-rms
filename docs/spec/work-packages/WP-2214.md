## Acceptance

1. Identity exposes an opt-in Node credential provider implementing its existing port. It generates
   exact 32-byte CSPRNG Session/CSRF credentials as unpadded base64url and UUIDv7 Session references.
2. The caller supplies exactly 32 bytes of selector key material. The provider copies it immediately
   and derives lowercase HMAC-SHA-256 selectors with a versioned prefix and distinct Session, CSRF
   and operation-intent domains. Raw credentials, intent and key material are never returned as a
   hash input detail, persisted, logged or placed in errors.
3. Selector equality accepts only canonical fixed-length digests and uses constant-time comparison.
   Operation intents are non-empty and bounded to 4096 UTF-8 bytes. Invalid input fails with the
   existing bounded Guest Session input error and no cause.
4. Tests prove output shape/decoded entropy length, UUID version, exact known HMAC, domain
   separation, copied key material, key/intent bounds, equality and malformed digest denial.
