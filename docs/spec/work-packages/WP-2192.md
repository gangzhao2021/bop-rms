  only through validated references or ports.

## Acceptance contract

1. Store configuration is Brand + Store scoped and immutable by version. It records locale, CAD,
   IANA time zone, controlled address/contact/receipt/tax/payment/capacity references, explicit
   Brand-base compatibility, source and effective period; no foreign value or raw restricted
   address/contact record is persisted.
2. Service configuration supports Dine-in/Pickup/Delivery, weekly and date-exception hours,
   cutoffs, lead time, Business Day Start (default `04:00:00` local), holiday/temporary closure and
   safe mode-specific pause. Overlap, duplicate, invalid local-time and incompatible base input
   fail closed. DST conversion remains instant-to-local and never guesses a nonexistent or
   ambiguous local instant.
3. Save draft, validate, submit, independently approve and publish/schedule Commands require exact
   Brand/Store scope, purpose, permission, expected version and idempotency. Publish additionally
   requires validated Publishing and Live Gate evidence references. No external success is inferred.
4. Persistence is append-only for configuration versions, service periods and operation evidence;
   forced Store RLS prevents Brand-only or cross-Store reads/writes.
5. `STORE-LIST`, `STORE-DETAIL`, `STORE-SETUP` and `STORE-HOURS-SERVICE` expose source + effective
   period, ordered setup validation, hours/service configuration and all canonical loading/empty/
   denied/not-found/offline/stale/conflict/error states. Restricted steps remain permission-trimmed.
6. This WP creates no Store Capability/Feature Flag (WP2193), Live Gate decision (WP2194), real
   Store/address/contact, foreign configuration, approval, publication, Event or external mutation.
