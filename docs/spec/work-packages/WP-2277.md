## Bounded owner transaction

Add an immutable regeneration-operation table and an exact unique scoped Session/generation index
on the existing capability table. The owner adapter supplies resolveActiveJoin (one coherent current
Active Session/latest compatible generation), resolveRegenerationOperation and regenerate. It exposes
no raw selector lookup or Guest/Cart authorization. Incompatible assignments return no current Join
state; Move-related reissuance remains separate.

Validate closed scoped Session/capability/Audit inputs and canonical intent before writes. Lock the
operation, then the same Table advisory lock/row used by existing writers, then Session and current
capability rows. Revalidate current assignment, Active Session/version, available occupied Table and
exact latest capability/version. Recompute the public capability transition: old Active becomes
Revoked; Consumed/Expired remains unchanged. Insert the new generation, immutable result and public
Audit in one transaction. No Session/assignment version is invented or advanced by regeneration.

Same operation/intent/Actor converges on original history; changed intent/Actor or competing state
conflicts. Lost acknowledgement resolves original history without returning unused raw credentials;
Audit failure rolls back predecessor/new-generation/history changes. The public Staff service stays
the authority boundary. Historical reads are scoped facts, not new credential grants.
