## Bounded read

Provide the existing DiningCartParticipationOptions.repository.readCurrent through one current
PostgreSQL statement joining only Dining's Table, Session and Participant with full Tenant/Brand/
Store scope and exact Session/Participant identity. Copy/validate closed request and bounded rows,
canonical server-supplied observation time and owning snapshots. Return minimal frozen Session,
Participant and Table-start evidence to the existing Query. The assignment version comes from the
current Session assignment; Table aggregate revision is a distinct value and must not replace it.

Current Table must be Published, Available and occupied by the requested Active Session; Participant
must be Active and belong to it. Missing, inactive, incompatible or future-dated facts return no
current snapshot. Foreign bound scope cannot select another Store. Malformed dependency data and
errors are bounded; no raw exception or unrestricted reference enters telemetry. Each call rereads,
with no cache, write, Audit, Event, capability or credentials. Participant's owner read metadata
includes the already accepted public-query-contract pattern; no foreign private access is admitted.

The public Query remains internal facts only. Caller identity/action authorization and atomic
Closing-versus-Cart-write coordination remain separate. A snapshot is not a future lease or a
promise that state cannot change after the statement completes.
