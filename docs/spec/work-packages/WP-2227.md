## Implementation and ownership

API owns transport/composition only. Share the existing complete HTTP route-template inventory
between request instrumentation and the real telemetry factory, including Entry, Quote and Merchant
Session routes already recognized by the app. Unknown paths still collapse to unmatched; no raw
path, query, credential, scope ID or payload becomes an allowed metric attribute. A synthetic
backend uses the existing observability test seam to verify actual factory acceptance.
Mounted routes must match their complete registered mount/template combination; an unregistered
mount remains unmatched and cannot turn raw paths or parameters into telemetry labels.

End SSE responses and clear local timers/listeners before awaiting registry cleanup. Bound each
owned lease release by the accepted 25 seconds (tests may inject a shorter positive bound). Track
pending release work, reuse one drain promise, stop new admission synchronously and report failed
or timed-out cleanup rather than claiming successful release. Late release rejection must be handled.
Invalid/late leases remain denied without withholding the HTTP error behind an unbounded release.
The port cannot cancel a registry operation: timeout is unknown remote cleanup, not proof of release
or permission to invent a free registry slot. Live shared-registry recovery remains its owning gate.
