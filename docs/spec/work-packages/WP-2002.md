## Contract and ownership

The Contract package owns an exact declarative Consumer Contract for every accepted Event Catalog
producer-to-consumer relation. Each relation binds the versioned Consumer identity, owner Module,
Event type and accepted schema versions, Tenant scope, ordering and replay safety. The compatibility
gate fails closed for missing, duplicate, orphaned, unsupported-version, scope-mismatched or unsafe
replay declarations.

Existing executable Consumer registrations use the same versioned names as the Event Catalog.
This WP changes no Event identity or payload, business side effect, persistence, retry policy,
external broker, Provider or deployment. Module-manifest dependency completeness remains WP-2004.
