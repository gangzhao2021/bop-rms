## Scope and acceptance

Add an explicit server clock port to the internal Order creation service. Reject invalid/backward
clock readings. Authorization and Guest usability use current time, including after awaits.
New work cannot use a future request instant or expired Checkout evidence/Cart lifecycle.
Recheck after Checkout, source, Business Date, Audit and final authorization waits before commit.

Dining context; revocation or rebinding denies the write. Replay requires current authorization
but returns the original immutable submission without refreshing Quote/capacity or retry clocks.

Keep the original submission/Audit/Event/number timestamps. A commit acknowledged after a wait
returns its verified durable result; never pretend a post-commit timeout rolled back history.
The future repository must enforce its own conditional source/current-time write fences; service
checks alone are not proof of a database commit-time or cross-domain authority guarantee.
