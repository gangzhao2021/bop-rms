## Contract and ownership

Add a closed Pricing request identity/record contract and one owned append-only request table.
Identity binds operation reference, Brand/Store, Guest Session reference, Cart reference/version;
its canonical digest excludes observation time and current pricing/configuration facts. Store only
opaque references and hashes, never Session/CSRF credentials. Record the original Quote reference,
Created/Existing Quote outcome, recorded request time and exact 24-hour expiry. Millisecond UTC
and complete linked Quote scope/Cart/version are mandatory. A historical replay does not renew
Quote expiry or establish current payable validity. Expired or changed intent returns a fixed conflict.

The owner adapter exposes exact-identity lookup and append. Caller owns current Session/CSRF,
purpose/permission and authoritative Cart/configuration validation before either operation. Its
constructor copies Brand/Store. Queries set local RLS context and explicitly filter scope plus key.
Before new append, lock scoped request identity, resolve a prior record, then invoke the existing
atomic Quote store in the same borrowed transaction and insert request history. Concurrent same-key
candidates return the first committed Quote; a second Quote/Audit is not created. Changed identity
cannot read that Quote. Record insertion failure rolls back Quote/children/Audit as one transaction.

Copy candidate Quote/Audit data before awaits. A new request must reference a Quote current at the
server observation instant; a valid original request replay may return its now-expired historical
Quote. The underlying Quote-store Created/Existing outcome is persisted and returned consistently.
Hash/reference providers are explicit technical ports. No background replay or automatic retry.
