## Acceptance

1. Optional scoped adapter loads consistent Cart/Items and atomically appends validated attachment,
   line evidence and Audit. Attachment never changes Cart contents/version or lifecycle deadlines.
   Recheck locked Cart version, active lifecycle and every line's Catalog identity/quantity.
2. Read/write money as bigint or decimal strings, including values above JavaScript safe integers.
   Return deterministic reference-sorted evidence lines on initial commit and replay; table schema
   does not encode Pricing array order. Preserve warning order and all other immutable facts.
3. Exact replay and concurrent identical candidates return original attachment with one Audit;
   changed intent/quote candidates conflict. Different operations may append requote history for
   the same Cart version. Existing service remains responsible for authorization and Pricing.
   Its replay avoids another Pricing call; concurrent differing Quote results may conflict and
   subsequently retry through the existing operation lookup.
4. Real isolated PostgreSQL tests cover precision, CAS, stale/terminal Cart, line mismatch, RLS,
   immutable history, fresh reads, no Pricing call on replay, and rollback after Audit. Retained
   Cart browser gate and full local verification pass; register the exact adapter and negative
   ownership/adjacent-file/driver tests as part of this work package.
