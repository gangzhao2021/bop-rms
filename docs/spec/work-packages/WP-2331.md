Session/CSRF authority and Catalog owns selection validation. Reauthorize exact Session facts with
monotonic fresh server time before Catalog, before new commit and before result disclosure.
Check Session expiry after authorization awaits and the original loaded Cart lifecycle before new
work; never use the proposed mutation's refreshed lifecycle to revive an expired Cart. Preserve
bounded existing errors through the generic service's dependency wrapper. Keep original intent,
expected version, timestamps and durable history unchanged. Original authorized retries bypass
new-work lifecycle checks and never repeat Catalog validation or writes. This observation fence
is not an atomic authority lease over a database commit.

Tests cover Add/Update revocation and identity drift while Catalog waits, expiry before/during
Catalog, expiry during authorization, backwards/invalid clocks, denial during replay and after
commit, and exact original recovery without duplicate writes. Credentials reach only Identity;
notes/options stay in existing restricted owner persistence and never enter new diagnostics.
No schema, public contract, new policy, Dining behavior, financial producer or external action.
