## Goal

Create a minimal, reproducibly installable, version-pinned TypeScript monorepo root so WP-0002–WP-0007 can add workspaces, tooling, runtime skeletons, and local services without reopening the toolchain decision.

## Scope

- Private Git-aware repository root and isolated WP branch/worktree
- Exact Node 24.18.0, Corepack 0.35.0, pnpm 11.13.0, and Turborepo 2.10.5 baseline
- pnpm workspace discovery and canonical Turbo task graph
- Root package-manager, text, ignore, and editor policy
- Reproducible lockfile
- Root `AGENTS.md`, specification index, and minimum setup documentation
- Minimal read-only GitHub Actions workflow exposing exactly `bootstrap / verify`
- Auditable GitHub Free solo-governance evidence without claiming unavailable server-side enforcement or independent review

## Non-goals

- `apps/`, `packages/`, or `tooling/` implementation
- TypeScript or business source files
- Express, React, PWA, worker, database, Docker Compose, migration, seed, or provider setup
- Full ESLint, Prettier, Vitest, Playwright, contract, deployment, or CI matrix configuration
- Domain models, API/event schemas, production resources, secrets, or credentials

## Deliverables

- `package.json`, `pnpm-workspace.yaml`, `pnpm-lock.yaml`, `turbo.json`
- `.npmrc`, `.nvmrc`, `.gitignore`, `.gitattributes`, `.editorconfig`
- `AGENTS.md`, `README.md`, `docs/spec/README.md`
- `docs/spec/work-packages/WP-0001.md`
- `.github/workflows/bootstrap.yml`

pnpm 11 reads project policy from `pnpm-workspace.yaml`; `.npmrc` is intentionally restricted to the registry setting and contains no authentication. This preserves the Section 77 package-manager policy intent using the accepted pnpm 11 configuration surface.

## Verification

Run from the repository root:

```bash
test "$(node --version)" = "v24.18.0"
test "$(pnpm --version)" = "11.13.0"
test "$(pnpm exec turbo --version)" = "2.10.5"
pnpm install --frozen-lockfile
pnpm list --depth 0
pnpm exec turbo run build --dry=json
node -e 'JSON.parse(require("node:fs").readFileSync("package.json")); JSON.parse(require("node:fs").readFileSync("turbo.json"))'
python3 -c 'import yaml; [yaml.safe_load(open(f, encoding="utf-8")) for f in ("pnpm-workspace.yaml", ".github/workflows/bootstrap.yml")]'
git diff --check
```

Also verify the real path is outside `/mnt/*`, repository tools resolve inside WSL, LF/case policy is preserved, `AGENTS.md` remains below 8 KiB, no tracked secret or generated dependency directory exists, the lockfile is unchanged after a second frozen install, and the Pull Request emits one successful `bootstrap / verify` check. The Actions service parsing the workflow and pnpm parsing the workspace file provide the clean-clone CI YAML evidence; the Python command is an additional local check when PyYAML is available.

## Security and rollback

Do not track registry tokens, `.env` files, provider credentials, signed URLs, machine-specific absolute paths, or unreviewed install scripts. GitHub Actions permissions remain read-only. Roll back only through normal Git changes; version changes require a reviewed IDR revision and regenerated lockfile.
