## Resolved contract and boundaries

The standalone routes are `/menu`, `/menu/search` and `/menu/items/:sellableId`. All three read
only WP-1026's side-effect-free Published Menu resource. The exact public Store, channel, order
type and locale originate in WP-1700's server-established QR context and remain in React page
memory; direct navigation or refresh without that context returns a rescan state. Search and
section filters remain bounded Catalog query inputs. Detail selects one exact UUIDv7 public
Sellable reference from the returned immutable menu snapshot and does not invent a detail API.

The UI renders localized Menu/Section/Sellable names, explicit availability, controlled allergen
and cross-contact disclosures, assistance guidance and Option Set min/max summaries. The accepted
DTO deliberately has no media/portion/variant facts and declares display price/tax unavailable;
the UI states those boundaries and never renders zero, a fabricated image, tax exemption or an
allergen-free promise. Configuration and Cart mutation remain WP-1702.

No Service Worker, persistent/private cache, Web Storage, IndexedDB, analytics, mutation,
background replay, private Domain read, new API route, DTO extension, dependency, migration,
manifest, deployment or Figma action is authorized.
