# WP-2259 - Quote Option Evidence Guard

## Authority and readiness

Owner authorizes successive bounded implementation and verified local commits. Baselinefbf1ed6,
branch codex/wp-2259-quote-option-evidence-guard. Composite Sections0–97, WP-1202/1203,
WP-2225 and WP-2255–2258 preserve exact financial facts and original authorized historical replay.
The current v1 PriceQuote line carries a resolved sellable price but no selected-option price
breakdown. Ordering currently passes options to Pricing and verifies only the base line identity.
An adapter ignoring those options can therefore attach an incomplete base-price Quote.

## Contract and scope

Ordering denies a new attachment with CART_QUOTE_INVALID before calling Pricing or repository
attach whenever any current Cart item has a nonempty option selection. Do not infer a zero price,
free-option policy or option totals from Catalog display facts. Current Session authorization,
Cart version and lifecycle validation still run first. The already-authorized exact operation
replay stays historical and does not reload current Cart, call Pricing or renew Quote expiry.
Plain items and Catalog rule evidence with no actual selection remain supported.

This is a temporary fail-closed admission boundary, not an option-pricing implementation. A future
Pricing-owned versioned option-price contract and source producer must precede lifting this guard.
No mutation of Cart, Quote, Audit, migration or previously accepted history is introduced. No HTTP,
UI, public error-code or dependency change. No invented Store/tax/Provider facts or readiness claim.
