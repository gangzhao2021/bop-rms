## Contract and composition

Compose public Identity Session, Ordering Pickup Quote entry/Cart stores and Pricing request store.
Use separate caller-owned bounded Session/read Cart/write Quote/Pricing transaction runners and
explicit reference/hash/Audit providers. A mandatory server-side candidate producer supplies actual
Pricing Quote/Audit facts; there is no synthetic/default price or tax source in application code.
Resolve an existing scoped Pricing request before invoking that producer; verify a new candidate's
complete codec and exact Cart/line/version identity before appending its request. Map request key
conflict to Ordering's existing conflict. No new financial calculation or foreign private SQL.
Copy and deeply freeze the server-owned Pricing request before any await or candidate call.
Reject an explicitly incompatible resolved price service mode before persistence. Check fresh
server time after final authorization as well, without extending either request history window.

The HTTP port copies the closed command before awaits. First authorize and attach through Ordering,
then resolve the exact scoped Pricing operation result using receipt identity and server time.
Require full Quote and request/attachment scope, identities, monetary totals, currency metadata,
line Catalog evidence, warnings and original timing to agree. Copy complete facts before awaits.
Reauthorize by exact attachment replay after the history read; require the same immutable receipt.
Any post-command missing, corrupt or denied result stays Unavailable rather than falsely rejecting
a committed command. Created/Existing Pricing outcome maps consistently to Created/Current even
on replay; historical expiry is not renewed. No automatic retry or invented requote comparison.

Expose optional local-runtime Quote configuration, requiring Cart reads and explicit write/fact
providers. Keep default unavailable and loopback-only development/test boundary. No production
configuration, real Store/tax/Provider facts, deployment, main merge or push. This adds local
composition, not external evidence or completed customer-journey readiness.
