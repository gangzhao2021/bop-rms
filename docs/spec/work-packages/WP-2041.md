## Resolved test boundary

WP-2041 composes the existing application and persistence isolation suites into one focused
security gate. The application matrix proves route-derived Tenant Context, current Membership /
Store Assignment, deny-first Permission, exact object scope, uniform not-found/foreign/sibling-
Store denial, Store-switch rotation and request-local cleanup. The isolated PostgreSQL matrix
proves transaction-local context, pool reset, forced RLS, policy constraints and least privilege.

The test does not infer that application denial alone proves database isolation or that RLS grants
application authority; both layers must pass. It adds no Tenant fact, table, policy, runtime role,
credential or production resource. Real multi-account, production-role, load and penetration
evidence remains gated.
