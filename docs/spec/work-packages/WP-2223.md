## Implementation and ownership

Ordering owns a public, opt-in scoped PostgreSQL Cart query adapter over its existing private
`cart` and `cart_line` tables. Require a trusted Brand/Store scope and caller-owned read-only
transaction runner. Set transaction-local scope, query one Cart using explicit scope predicates
on parent and children, and parse the complete result with the accepted Cart parser. Return null
only for an absent Cart. Reject malformed, foreign or duplicate results with a bounded dependency
error. Copy scope at construction. No logs, JSON-to-browser shortcut or cross-Domain private SQL.
Application authorization and exact Cart/Session binding must precede use; possession of a Cart
reference or this adapter does not grant read authority. Do not wire it into an HTTP handler yet.

The existing fail-closed database-asset gate also requires exact module/schema/table/path
registration for this adapter. Register only this file and retain all driver/other-asset denials,
with positive and changed-owner/schema/table/path regression evidence. This necessary gate update
was identified by the first full verification; no check is removed or skipped.

## Acceptance

1. Read legacy and configured Cart snapshots with correct identity, lifecycle, item attribution,
   catalog selection evidence, options and synthetic note; use deterministic item ordering.
2. Null for missing/foreign scoped Cart, explicit Brand/Store predicates and forced RLS, strict
   input validation before any query, immutable scoped constructor and parsed frozen results.
3. Malformed driver rows, mismatched parent/child scope, duplicate results and driver faults yield
   bounded errors without SQL, credentials or note content. Reads never mutate Cart facts.
4. Isolated PostgreSQL proves real reconstruction, cross-Store and cross-Brand denial, least
   privilege, read-only transaction mode and cleanup/context release.
5. Exact frozen install; affected Ordering/database format/lint/typecheck/test/build; retained
   Cart acceptance plus new adapter case; complete root verification and tracked secret/diff review.
