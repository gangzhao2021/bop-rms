## Acceptance

1. Opt-in scoped PostgreSQL adapter loads consistent Cart/Item snapshots, persists exactly the
   existing Domain transition, increments version once, and atomically appends operation plus Audit.
2. Exact concurrent same-operation requests recover the original record. Changed action, session,
   intent, snapshot or expired replay conflicts. Different operations with stale Cart versions
   conflict. New terminal mutations cannot resurrect Cart or remove Item/Quote history.
3. Isolated real PostgreSQL acceptance covers Abandon, due/not-due Expire, original replay,
   concurrency, scoped reads/RLS, append-only operation history, corrupt input, dependency error
   redaction and rollback after Audit. Existing Domain time/policy semantics remain unchanged.
4. Frozen install, Ordering checks, dedicated database gate, retained browser Cart regression and
   full local verify pass. Existing owning acceptance script includes the new finite gate.
