# WP-2255 - Complete Price Quote Snapshot Codec

## Authority and scope

Owner authorizes successive bounded implementation and verified local commits. Baseline8d89b26,
branch codex/wp-2255-price-quote-snapshot-codec. Composite Sections0–97 and the existing Pricing
Quote contracts retain Pricing ownership, immutable history, exact integer money and resolved
historical evidence. This pure Domain codec has no authorization, database or external side effects.
Tenant/Actor/purpose/permission/idempotency and transactional Audit remain responsibilities of the
future owning application/store; this codec grants no authority to read or write a Quote.

Current SQL Quote tables do not preserve every CurrencyMetadata, ResolvedPrice, TaxResolution and
TaxCalculationExplanation field. Add a bounded versioned canonical JSON representation preserving
the complete existing v1 snapshot. Decimal strings encode bigint Money without Number conversion.
Decode rejects incomplete/unknown evidence, invalid shape, currency/provenance inconsistencies,
invalid time and arithmetic. Recalculate tax solely from the supplied historical rule and metadata
and compare its recorded explanation. Never consult current configuration to fill historical gaps.

The supported v1 factory has zero discounts/fees and empty promotion/warning/blocking arrays;
unsupported future states fail closed and require an explicit codec evolution. Validate selected
price structure and scope consistency, not current eligibility or proof that its digest is authentic.
Accept canonical encoded text only: bounded size/depth/node count, exact fields, deterministic key
order and decimal syntax. Native encoder rejects accessors, cycles and exotic containers without
calling toJSON. Decoded snapshots are owned and deeply frozen. Errors expose only a fixed code.
