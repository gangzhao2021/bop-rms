## Contract and ownership

The Domain Event Envelope is a closed exact transport contract. It requires UUIDv7 identity and
scope, PascalCase event / aggregate type, positive schema / aggregate versions, canonical UTC time,
approved producer namespace, explicit correlation and optional causation, exact System / Actor
shape, JSON-object payload and replay metadata, and an approved redaction classification. Unknown
top-level or Actor fields fail closed before persistence or dispatch.

Business payload shape, owner / consumer metadata and compatibility remain registered by the Event
Catalog. This WP changes no Event identity, payload schema, consumer, persistence or external broker.
