## Resolved local boundary

WP-2054 composes the accepted Media contract with deterministic upload, signed-download and outbound
hop validators. It rejects spoofed/polyglot/active content, oversize and malware-unknown objects,
private downloads without fresh bounded authorization, and every DNS/redirect hop that changes the
approved HTTPS host, resolves privately or forwards inbound credentials.

Synthetic bytes and IP addresses prove local policy only. No object, URL, credential or AWS control
is accessed or mutated.
