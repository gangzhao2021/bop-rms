## Resolved contract and boundaries

WP-1703 provides server-authoritative Quote creation/requote and the Customer review surface for
the exact current Cart Version. The existing Quote HTTP transport is corrected to the accepted
same-origin Guest Cookie + in-memory CSRF boundary; the browser never supplies a Customer Session,
Store, Actor, amount, tax or price fact. Entry, Cart and Quote share one dedicated page-memory-only
transaction context. The WP-1702 omission that left this context unset after real Entry success is
forward-corrected and covered by integration tests.

`CUST-CHECKOUT` renders Store/service context, Cart lines, exact server Quote subtotal/discount/tax/
fee/total, expiry, warnings/blocking reasons and explicit price-change reconfirmation. Quote is a
mutation with one retained in-memory Idempotency Key; unknown outcome retries only that operation,
conflict refreshes the Cart, and offline never queues/replays. Money remains decimal minor-unit text
from the server.

No Checkout Session/contact/capacity-hold public adapter exists in the repository. Those fields are
shown as unavailable, and Continue to Payment remains disabled with an owning-boundary reason.
WP-1704 owns Payment handoff/result. No Create Order HTTP, Provider, contact/PII collection,
capacity invention, tip policy, address/time-slot policy, persistence, Service Worker, dependency,
migration, deployment or Figma action is authorized.
