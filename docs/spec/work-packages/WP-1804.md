## Resolved contract and hard gate

WP-1403 owns the Store-scoped `kitchen_work_queue_v1` projection, WP-1404 owns exact-version
Kitchen lifecycle Commands, WP-1407 owns structured allergen acknowledgement and WP-1408 owns
runtime-inactive continuity evidence. No accepted Merchant HTTP adapter or production named-operator
Session composition exists.

This WP adds strict closed browser DTOs and canonical queue/detail routes. The default runtime is
unavailable and sends no request. A queue is actionable only when its projection is Fresh and its
operator state is Named. Locked, handover-required, stale and offline boards are visibly read-only;
the browser never queues or replays a Command. Missing hold, priority, exception and detailed safety
facts remain disabled or explicitly unavailable rather than invented.
