## Resolved local boundary

WP-2044 adds a deterministic, dependency-free high-confidence secret scan over the exact Git
tracked-file inventory. It blocks private-key headers and recognizable AWS access-key, GitHub token
and live Stripe secret formats. Positive canaries are constructed only at runtime so the scanner's
own source cannot become an implicit exception. Binary and oversized generated content is not a
tracked deliverable and fails/exits through explicit bounds rather than being silently decoded.

This local gate complements, but does not replace, WP-2050's pinned Gitleaks complete-history and
release-artifact evidence. It reads no environment, ignored secret file, Git object history,
credential store or external service and performs no rotation.
