## Resolved local boundary

WP-2045 is a focused security-review gate over the already accepted Payment webhook boundary. It
composes the exact raw-byte signature verification matrix with the durable Inbox and isolated
PostgreSQL acceptance so authenticity, scope binding, idempotency and transactional processing are
reviewed together. It adds no second verifier, Provider adapter, HTTP route or Payment fact.

The gate proves that request bounds and signature verification precede JSON interpretation; exact
Test/Live account scope and a five-minute timestamp window fail closed; current/next secrets have a
bounded overlap and never enter output; verified evidence is copied and revalidated before one
durable receipt; duplicate/conflicting delivery, retention, rollback, replay and completion
uniqueness retain their accepted behavior under forced RLS and least privilege.

Real Stripe configuration, endpoint delivery, secret rotation, Provider retry observation, WAF,
production retention execution and penetration evidence remain External Evidence gates. The review
does not convert their absence into a passing production claim.
