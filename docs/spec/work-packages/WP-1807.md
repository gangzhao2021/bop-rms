## Resolved contract and hard gate

The same-origin Session bootstrap is the sole authority for visible navigation. The browser accepts
only a closed array of exact Screen ID, label, canonical href and matching Permission tuples. It
does not derive access from role names, hide-only client flags, route patterns or Store labels.
Unknown screens, mismatched href/Permission pairs, duplicates, accessors and open data are rejected.

Navigation is refreshed by the existing Session rotation after Store switch. Absence means hidden;
it is not inferred from another entry. Direct route authorization remains the responsibility of the
owning server Query/Command and cannot be granted by a visible link. `IAM-ROLE-LIST` can be admitted
only with `identity.manage`; role editing data/actions remain gated by WP-2195 and are not invented.
