## Contract and ownership

Fulfillment remains sole owner of Pickup Aggregate phase, readiness, Handoff quantities, proof
verification and Completion. This WP adds a strict operational summary using only safe Store-scoped
public snapshots. It contains proof readiness, never Pickup Proof, token/code, verification payload,
recipient, Customer/contact, device identity or handoff evidence detail.

Quantity and phase invariants are closed: Pending has no ready quantity/time; Ready/InProgress/
Completed require all quantities ready plus source ready time; Completed additionally requires exact
handed-over == ordered and a source completion instant. Validated proof readiness is accepted only in
a ready-capable phase and grants no completion authority. Every generation exposes Business Date,
checkpoint, as-of/projected/rebuilt time, initialized-empty and a 2-second Fresh/Stale target. Stale
rows cannot authorize claim, proof verification or Handoff. Shadow persistence remains WP-1904.
